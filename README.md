# 🌿 VerdeMap Carajás

Mapa interativo voltado à visualização e organização de informações ambientais na região de Carajás.

O projeto tem como objetivo facilitar o acesso a dados, pontos de interesse e conteúdos relacionados ao meio ambiente, promovendo conscientização e informação acessível.

## 📌 Sobre o Projeto

O VerdeMap Carajás é uma aplicação web desenvolvida com:

- HTML
- CSS
- JavaScript

A plataforma permite:

- Visualização de mapa interativo;
- Acesso a detalhes de locais específicos;
- Página de dúvidas frequentes;
- Termos de uso.

## 🌎 Objetivo

O VerdeMap Carajás foi criado com foco em:
- Educação ambiental;
- Organização de informações geográficas;
- Acesso simplificado a dados regionais;
- Incentivo à conscientização ecológica;

## 🛠 Tecnologias Utilizadas
- HTML5, CSS3, JS, Leaflet e OpenStreetMaps
